# Smart Health Tracker

A professional Flutter Smart Health Tracker app with Firebase backend.

## Repository
[https://github.com/ramysaid200/Smart-Health-tracker-app](https://github.com/ramysaid200/Smart-Health-tracker-app)

## Features
- **Dashboard**: Real-time summary of your health metrics.
- **Step Tracking**: Monitor your daily steps and progress towards goals.
- **Water Intake**: Track your hydration throughout the day.
- **Nutrition**: Log meals and calories.
- **Sleep Tracking**: Record sleep duration and quality.
- **Vitals & Weight**: Keep a history of your weight and health vitals.
- **Medication Reminders**: Never miss a dose with scheduled notifications.
- **Analytics**: View trends and history of your health data.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ramysaid200/Smart-Health-tracker-app.git
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the app**:
   ```bash
   flutter run
   ```

## Firebase Setup
This app uses Firebase for authentication and data storage. You will need to set up a Firebase project and add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) files.
